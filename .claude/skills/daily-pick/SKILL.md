用 2026-10 定版策略（v3）对指定日期做盘后扫描。前提：该日数据已同步（未同步先走 `/sync-market-data`，其中会更新沪深300 指数缓存——regime 门依赖它）。单次约 1 分钟。

## 定版策略 v3（daily-scan --recommended）

- 股票池：沪深 A 股，排除 ST/退市/上市 <250 交易日/北交所
- 市场门①（广度）：启动广度 ≥**0.9%**（不要求市场涨幅）
- 市场门②（regime）：**沪深300 收盘 > MA20**（2026-10-17 加入；长周期验证 2023-04~2026-10：被挡日（多为 2024 年 7~9 月微盘流动性危机）均值 -0.88%，保留日 +2.12%。MA120/MA250 会错过 V 型反转初期，已否决。指数缓存缺失时门**关闭**——不选股，先同步数据）
- 启动信号 V0+：60 日区间位置 ≤35% + 量能 1.8~2.5× + MA5>MA20 上行 + 20 日涨幅 ≤25%
- 总分 ≥60（45% 技术 + 55% 质量）+ 质量分 ≥55
- 仓位规则：触发日取总分 **top 10 等权**；收益按 **0.10% 双边成本**扣减后跟踪
- 退出假设：5% 止盈 / 10 日持有
- **次日买入执行规则**（scripts/make_order_sheet.py 生成含具体限价/股数的清单，gap 规则由 gap_entry_analysis.py 在 713 信号上验证）：
  - 前一晚挂集合竞价限价单：**限价 = 信号收盘价 × 1.02**，股数按限价 100 股整手取整（9:25 开盘价 ≤ 限价即以开盘价成交，与回测入场假设一致）
  - 高开 > +2% 自动不成交 → 9:30 撤单（+2~5% 高开桶胜率仅 57%、均值 -0.43%，追入负期望）；低开 ≤ -5% 手动撤单（隔夜闪崩）
  - 被跳过的仓位资金收盘后均分给当日其余成交标的
  - 无常规止损（数据否决，见记忆 final-strategy-config）；可选保险线收盘 ≤ 买入价×0.88 → 次日卖出
- 诚实预期：**年化约 6.4%**（资金在场 20.9%，空仓期买货基 +~1.5pp → 约 8%；核心优势是回撤规避）。回测依据（46 个月 856 个交易日，扣 0.1% 成本）：53 个触发日，日胜率 64%、日均 +2.12%、等权复利 +186%；单笔胜率 64%、均值 +2.41%；2023-24 熊市段 +40.3%（v2 无 regime 门为 -34.9%）。

## 执行步骤

1. 确认数据到位（缓存最后一天 = 目标日；否则先 `/sync-market-data`）：

   ```bash
   .venv/bin/python -m qfree.cli daily-scan --recommended --offline-scan --as-of <YYYY-MM-DD> --workers 12
   ```

   输出写入 `outputs/daily_<日期>_selected.csv`，并追加门禁状态到 `outputs/daily_tracking.csv`。

2. 报告解读要点：
   - `gate pass: False` → **空仓是策略的正常输出**，弱市日（广度 <0.9% 或沪深300 ≤ MA20）就该空仓，不要建议绕过市场门买入。可附“无视市场门的参考名单”（`--min-startup-breadth 0 --min-market-ret5 -1`，其余同定版参数）并明确标注仅供参考。
   - `selected: N` → 展示表格：代码、名称、行业、总分、质量分、20 日涨幅、60 日位置、20 日均成交额（万元）。**随后必须生成次日买入清单**（用户给了本金就带 `--capital`，默认 50 万）：

     ```bash
     .venv/bin/python scripts/make_order_sheet.py <YYYY-MM-DD> [--capital 500000]
     ```

     展示清单表格 + 执行规则（跳过条件、止盈价、保险线），文件写入 `outputs/daily_<日期>_orders.csv`。提醒用户：成交后回填实际买入价并记录到持仓台账。

3. 后续收益验证（可选，用户要求时）：对选中的票用次日开盘价买入，跑事件研究：

   ```bash
   .venv/bin/python - <<'EOF'
   # evaluate_events(signals, bars, (5,10), exit_modes=("profit_target_close",), profit_target=0.05)
   EOF
   ```

   报告每个持有期的胜率/均值/中位数，并与同期市场 5 日涨幅对比。

## 注意

- `--recommended` 已内置所有定版参数（量能上限 2.5×、q≥55、广度门、regime 门 MA20），不要手动重复传这些参数；`--no-regime` 可单独关闭 regime 门做对照。
- token 在环境变量，绝不显示。
- 若用户要调整策略参数，先看记忆 `final-strategy-config` 里列出的“已被否决的过滤”（20 日跌幅下限、min score ≥70、流动性下限、收盘位置>0.65、ret5≤8% 等），不要重蹈覆辙；要验证新想法就用 `scripts/` 下的对照实验模式（bars 一次加载 + fork 并行 + evaluate_events）。
- 参考名单里重复多日出现的股票（连续信号）历史上质量更高，值得单独标注。
